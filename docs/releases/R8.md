# R8 — Server Execution Mode

Status: **Complete**

R8 adds an explicit Experimental Python-reference-host server execution mode over the existing HTTP, routing, and CORS primitives. It is not a general web framework or a multi-host server guarantee.

Run the finite example:

```bash
genia serve examples/r8_server.genia
```

From another terminal, make its single configured request:

```bash
curl http://127.0.0.1:8088/
```

Output:

```text
hello from genia
```

After that request, `max_requests: 1` makes the server close and the `genia serve` process exit successfully. Serve mode evaluates only the entry file, does not dispatch `main`, and activates only valid entry-file `@server`, `@route`, and optional owner-bound `@cors` descriptors.
