# R9 — Value Templates & Representations

Status: **Active — E9-1 implemented**

E9-1 establishes the Experimental Template foundation without adding a second matcher or nominal type system. A named reusable pattern is an ordinary one-argument Outcome matcher that can be stored, passed, returned, imported, called directly, and composed through the existing matcher operators.

Run:

```bash
genia -c 'pattern Id(record) = some(record.id)
apply_template(template, value) = template(value)
[apply_template(Id, {id: 7, name: "Ada"}), {id: 7, name: "Ada"} @? Id]'
```

Output:

```text
[some(7), some({id: 7, name: "Ada"})]
```

The direct call exposes the matcher's `some(7)` payload. `@?` keeps its existing behavior and returns `some(original_subject)` on success.

Open/refinement shapes, exact/closed shapes, representation carriers, JSON, and JSON Schema remain later R9 work and are not implemented by E9-1.
