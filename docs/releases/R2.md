# R2 — Native Test Kernel

Status: Complete. See `docs/strategy/release-roadmap.md` for full scope.

Theme: let Genia test Genia where Genia-level tests make sense.

## What to run

R2's headline capability is writing and running tests in Genia itself with
the legacy `test(name, body)` registration form and the `genia test <file>`
execution mode.

```genia
add(x, y) = x + y

test("add combines two numbers", () -> assert_eq(add(2, 3), 5))
test("add is commutative", () -> assert_eq(add(2, 3), add(3, 2)))
```

Run it:

```bash
genia test path/to/this-file.genia
```

Output:

```text
total=2 passed=2 failed=0 errored=0
PASS add combines two numbers
PASS add is commutative
total=2 passed=2 failed=0 errored=0
```

`assert_eq` raises a native test failure (reported as `FAIL`, not a runtime
`ERROR`) when the two values don't match; any other runtime exception in a
test body is reported as `ERROR`.
