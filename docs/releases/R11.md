# R11 — AI Composition

Status: **Active — E11-1 delivered; E11-2 through E11-8 remain planned**

E11-1 adds one Experimental public entry point, `model/4`, which returns an
ordinary callable over ordinary text request/response values and existing
Outcomes. The only implemented provider is an explicit deterministic Python
test fixture; this slice performs no network operation and supplies no ambient
provider, credential, or authority.

Run the fixture example from the repository:

```bash
uv run python -m hosts.python.exec_model_fixture 'm = model(model_provider_fixture, {id: "fixture-text", timeout_ms: 1000}, model_credential_fixture, model_authority_fixture)
m({messages: [{role: quote(user), content: {kind: quote(text), text: "hello"}}], output: {kind: quote(text)}})'
```

Output:

```text
some({message: {role: assistant, content: {kind: text, text: "fixture reply"}}, finish_reason: stop, usage: some({input_tokens: 2, output_tokens: 3, total_tokens: 5})})
```

The request is validated before credential declassification, audit, or provider
attempt. A valid invocation declassifies through the existing R10 authority and
makes exactly one synchronous attempt; it never retries. Results use existing
`some`, `none`, and `err` values with the closed E11-1 response and failure
shapes documented in `GENIA_STATE.md` and `GENIA_RULES.md`.

This page does not claim R11 completion. JSON structured output, a real
provider/network adapter, cross-mode hardening beyond the explicit fixture,
Flow conversation composition, the validated-pipeline proving case, tools,
agents, streaming, retry/fallback, and retrieval are not implemented by E11-1.
