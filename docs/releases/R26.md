# R26 — C++ REPL and Data Bridges

Status: **Complete — R26-1 (REPL) and R26-2 (Bytes/UTF-8 and strict JSON)
both merged.** `GENIA_STATE.md` remains final authority for implemented
behavior.

R26 extends the bounded C++ host with three independently gated portable
capability families:

| Capability | C++ declaration | Portable observation |
| --- | --- | --- |
| `repl` | `supported` | scripted REPL sessions: persistent successful bindings across complete submissions, canonical result echo to `stdout`, normalized failure diagnostics to `stderr` with session recovery, successful EOF termination |
| `bytes_utf8` | `supported` | opaque Bytes value, `utf8_encode`/`utf8_decode` round trip for well-formed input, `<bytes N>` display |
| `json_strict` | `supported` | full strict `json_decode`/`json_encode`: objects, arrays, strings/Unicode, booleans, `null`, 128-container nesting bound, duplicate-key rejection, BOM rejection, deterministic sorted-key/indented encode layout |

ZIP is explicitly excluded from R26 (deferred, contract-first placement
pending). `debugger_stdio` is deferred (#1025). `json_compat`
(`json_parse`/`json_stringify`/`json_pretty`, `parse_jsonl_record`) is
decided **not portable** by contract and remains permanently Python-host-only
— it is not an R26 gap.

## Small runnable examples

### REPL (scripted session)

Shared CLI case `spec/cli/repl_persistent_binding_basic.yaml`, passing in
both the Python reference host and the bounded C++ host:

```text
$ genia
x = 1
x + 2
```
```text
1
3
```

A binding from an earlier submission (`x = 1`) is available to a later one
(`x + 2`); each successful submission's final value is echoed to `stdout`.

### Bytes/UTF-8

Shared eval case `spec/eval/r19-unicode-utf8-encode-decode-roundtrip.yaml`:

```genia
utf8_decode(utf8_encode("hello 漢字 😀"))
-- "hello 漢字 😀"
```

### Strict JSON

Shared eval case `spec/eval/json-representation-number-boundaries.yaml`:

```genia
low = unwrap_or(0, json_decode("-9007199254740991")) |> representation_match("json") |> unwrap_or(0)
high = unwrap_or(0, json_decode("9007199254740991")) |> representation_match("json") |> unwrap_or(0)
fraction = unwrap_or(0, json_decode("1.5")) |> representation_match("json") |> unwrap_or(0)
[low, high, fraction]
-- [-9007199254740991, 9007199254740991, 1.5]
```

capability registry, shared-spec runner, and evidence format. No new

`tools/spec_runner/host_parity_gate.py` reports `repl`, `bytes_utf8`, and
