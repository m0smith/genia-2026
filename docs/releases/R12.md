# R12 — Retrieval & Grounding

Status: **Active — E12-1 through E12-6 delivered**

E12-1 adds Experimental portable document/chunk/provenance behavior through one
ordinary `chunk/2` call. It validates a closed document and one list of spans,
slices the original text in Unicode code points, and owns exact source metadata.
It makes no provider call and adds no embedding, index, retrieval, reranking,
grounding, model, credential, or citation behavior.

Run:

```bash
genia -c 'doc = {id: "doc-1", text: "A😀éZ", meta: represent("json", {source: "fixture"})}
chunk((_text) -> [{offset: 1, length: 2}], doc) |> unwrap_or([]) |> map((item) -> [item.text, item.source])'
```

Output:

```text
[["😀é", {doc_id: "doc-1", offset: 1, length: 2}]]
```

The chunker supplies only exact `{offset, length}` spans. `chunk/2` constructs
text, document identity, source, and metadata from the validated original
document, preserving returned order and allowing overlap/repetition. A valid
empty span list returns `some([])`; the first malformed or out-of-bounds span
returns indexed `chunk-invalid`.

## E12-2 — explicit chunk/query embedding

capability returns an ordinary callable accepting exact chunk or query variants.
Successful output preserves the exact input identity and validates a nonempty
finite vector, exact dimensions, and the configured compatibility space. It
uses R10 `quote(embed_call)` authority immediately before one deterministic
offline attempt and never hides query embedding inside retrieval.

## E12-4 — explicit retrieval and compatibility guards

E12-4 adds Experimental `retrieve/4`. Its ordinary callable consumes an opaque
paired index handle, an explicit query embedding, and bounded `k`. It checks
private capability identity, exact space, then exact dimensions before one
authorized deterministic offline attempt. Results retain provider best-first
order and exact indexed provenance; valid empty results are absence.
