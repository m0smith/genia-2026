# R30 — Sheet Shaped Computation

**Status: Implementation merged.** Final release acceptance is a maintainer
decision on [#1340](https://github.com/m0smith/genia-2026/issues/1340).
[GENIA_STATE.md](../GENIA_STATE.md#sheet-shaped-computation-experimental)
remains the authority for implemented behavior.

## Delivered scope

On the Python reference host, the three new functions are **Experimental**.
`column/2` extracts exact cells in row order into a fresh List.
`with_column/3` appends a canonically distinct column to a new Sheet and
requires exactly the stored row count. `map2/3` validates a callee and two
equal-length Lists before invoking the callee once per pair in order.

Ordinary outer calls retain `none` propagation. Raw callback invocation
passes Outcome elements unchanged and retains Outcome results in the List.
Sheets retain immutable storage, explicit conversions and the existing
protected storage and sink rules. Scalar repetition requires explicit List
composition. The release changes neither syntax nor Core IR.

## Executable proving case

The [validated report](https://github.com/m0smith/genia-2026/blob/94d1769bbdd265f98ee5a4312789ee86aa57b874/spec/eval/r30-sheet-validated-report.yaml)
validates three records, collects clean records and diagnostics, then
explicitly converts the clean records into a Sheet. It extracts quantity and
price columns and computes line totals with `map2`. The accepted rows produce
(2 × 3 = 6) and (4 × 1/2 = 2), with grand total 8 and shares `3/4` and `1/4`.
The case appends both computed columns and asserts the exact CSV header and
rows, the rejected record's index and diagnostic context, and the source
Sheet's original CSV. C++ reports the case unsupported under `sheet_values`.
