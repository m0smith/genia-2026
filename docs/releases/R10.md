# R10 — Configuration & Secrets

Status: **Active — E10-1 through E10-6 provider/default/protected-carrier/sink/declassification/cross-mode slices implemented**

E10-1 adds explicit immutable configuration providers and exact raw-string lookup. E10-2 adds missing-only lazy defaults and proves explicit Outcome conversion plus callable Template validation. E10-3 adds protected acquisition/matching/transport. E10-4 adds recursive diagnostic redaction and pre-effect sink rejection. E10-5 adds exact host-injected authority declassification and non-sensitive audit. E10-6 verifies those semantics across evaluation modes without ambient acquisition, annotation injection, or request refresh. The proving-case slice is not implemented by this page.

Run:

```bash
genia -c 'pattern Positive(value) = refinement_match((n) -> n > 0, value)
provider = config_provider([{kind: quote(values), values: {PORT: "8080", EMPTY: ""}}]) |> unwrap_or(none)
secret_provider = config_provider([{kind: quote(values), values: {TOKEN: "fixture-token"}}]) |> unwrap_or(none)
token = secret_get(secret_provider, "TOKEN", quote(outbound_api)) |> unwrap_or(none)
[
  config_get_or(provider, "PORT", () -> "3000") |> parse_int |> Positive,
  config_get_or(provider, "EMPTY", () -> "3000"),
  config_get_or(provider, "MISSING", () -> "3000") |> parse_int |> Positive,
  display(token),
  protected_match("secret", token) |> some?
]'
```

Output:

```text
[some(8080), some(""), some(3000), "<protected>", true]
```

`quote(values)` is explicit descriptor data; it does not add a global `values` name. Sources are ordered highest to lowest precedence, copied at construction, and never refreshed during lookup. The Python reference host also supports `{kind: quote(environment)}` as a construction-time process-environment snapshot. Normalized failures omit configuration keys, raw values, source contents, and host exception detail.

`config_get_or` calls its zero-argument default once only for missing lookup. Empty and found values bypass it. Conversion is explicit (`parse_int`) and validation is the existing callable Template (`Positive`); neither acquisition operation coerces values.

`secret_get` requires a non-empty purpose symbol and creates exactly one reserved protected carrier. `protected_match("secret", token)` returns the original protected subject. Generic construction, matching, and stripping reject the reserved facet; protected values are not map keys and travel unchanged through ordinary containers and pipeline/Seq/Flow/Sheet/ref/process transport. Diagnostic rendering substitutes `<protected>` recursively, while sinks reject before effects. `declassify` is the sole reveal operation: an exact host-injected provider/purpose-scoped authority audits before returning one ordinary payload.

Ordinary eval, file, command, pipe, import, native-test, and serve-entry evaluation use the same explicit provider values and protection rules. Imports acquire only through explicit module calls. Serve entry snapshots complete before listener activation, and requests do not refresh configuration automatically. Existing annotations remain inert with respect to configuration.
