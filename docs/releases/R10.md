# R10 — Configuration & Secrets

Status: **Active — E10-1 provider and ordinary acquisition implemented**

E10-1 adds explicit immutable configuration providers and exact raw-string lookup. Later R10 defaults/conversion, protected secret, sink-safety, declassification, cross-mode, and proving-case slices are not implemented by this page.

Run:

```bash
genia -c 'provider = config_provider([{kind: quote(values), values: {PORT: "8080", EMPTY: ""}}]) |> unwrap_or(none)
[config_get(provider, "PORT"), config_get(provider, "EMPTY"), config_get(provider, "MISSING")]'
```

Output:

```text
[some("8080"), some(""), none("config-missing")]
```

`quote(values)` is explicit descriptor data; it does not add a global `values` name. Sources are ordered highest to lowest precedence, copied at construction, and never refreshed during lookup. The Python reference host also supports `{kind: quote(environment)}` as a construction-time process-environment snapshot. Normalized failures omit configuration keys, raw values, source contents, and host exception detail.
