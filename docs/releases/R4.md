# R4 — Lifecycle Generalization

Status: Complete. See `docs/strategy/release-roadmap.md` for full scope.

Theme: extract the proven test lifecycle shape into a portable lifecycle
contract.

## Why there's no `.genia` example here

R4 delivered a **data shape**, not a public Genia-language API: a lifecycle
plan is a validated map of phases (`name`, `action`, optional `scope` /
`always` / `description` / `metadata`) that stays inert — constructing or
validating a plan never executes anything. There is no Genia prelude function
that returns or consumes a lifecycle plan yet, so there is nothing new to run
from a `.genia` file for this release specifically. The plan shape is
Python-reference-host-internal utility code (`src/genia/lifecycle_plan.py`),
and its first (and still only) consumer is the existing native test path from
[R2](R2.md)/[R3](R3.md), used as inert descriptive data.

## What to run

This example runs directly against the Python reference host to show the
shape being validated and normalized — the same shape/behavior
`tests/unit/test_lifecycle_plan.py` exercises.

```python
from genia.values import GeniaMap, GeniaSymbol
from genia.lifecycle_plan import normalize_lifecycle_plan

def phase(name, action, **extra):
    m = GeniaMap().put("name", GeniaSymbol(name)).put("action", GeniaSymbol(action))
    for k, v in extra.items():
        m = m.put(k, v)
    return m

plan = GeniaMap().put("name", GeniaSymbol("test_lifecycle")).put("phases", [
    phase("setup", "lifecycle_setup", scope=GeniaSymbol("suite")),
    phase("run", "lifecycle_run_test", scope=GeniaSymbol("test")),
    phase("teardown", "lifecycle_teardown", scope=GeniaSymbol("suite"), always=True),
])

normalized = normalize_lifecycle_plan(plan)
print([p.get("name") for p in normalized.get("phases")])
print([p.get("always") for p in normalized.get("phases")])
```

Run it:

```bash
uv run python this_script.py
```

Output:

```text
[setup, run, teardown]
[False, False, True]
```

`always` defaults to `False` when omitted on a phase and is preserved as
`True` where set explicitly. Nothing in the plan executes — `phase["action"]`
values are portable symbols, not callables.
