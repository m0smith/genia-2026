# R25 — C++ Stateful Runtime and Concurrency

Status: **Complete — E25-0 through E25-5 merged and audited.** The ordered
authority and C++ PR stack has merged. `GENIA_STATE.md` remains final
authority for implemented behavior.

R25 promotes and implements only three independently gated portable families
in the bounded C++ host:

| Capability | C++ declaration | Portable observation |
| --- | --- | --- |
| `refs` | `supported` | synchronized opaque Ref identity, blocking unset reads, set, and atomic update |
| `cell_primitives` | `supported` | FIFO serialized updates, fail-stop preservation, generation restart, transactional nested sends |
| `process_primitives` | `supported` | local FIFO mailbox, one handler in flight, permanent fail-stop and normalized error observation |

Actor and ActorRef are absent. Supervision, distribution, placement,
scheduler/fairness guarantees, thread identity/count, timing thresholds, and
mailbox capacity policy remain outside R25. Portable actors belong to R38.

## Small runnable example

The Ref example below is a shared eval case (`spec/eval/r25-ref-basic-observations.yaml`)
that passes in the Python reference host and the bounded C++ host:

```genia
r = ref(10)
set_result = ref_set(r, 20)
update_result = ref_update(r, (x) -> x + 2)
[ref_is_set(r), set_result, update_result, ref_get(r)]
-- [true, 20, 22, 22]
```

## Evidence boundary

R25 reuses R16 protocol version `1`, its existing `eval` operation, capability
registry, shared-spec runner, and evidence format. The private
`r25_concurrency` fixture adds only deterministic accepted/completed quiescence
for causal observation; it is unavailable to ordinary programs.

The seven R25 shared cases cover:

- exact Ref observations and a causal blocking Process producer;
- Cell FIFO success/failure, restart generation isolation, and nested-send
  commit/discard;
- local Process FIFO handling and fail-stop observation;
- exact `none("nil")` return values from both asynchronous send surfaces.

## Implementation validation

The C++ stack passes Release CTest, clang-format, clang-tidy, ASan+UBSan, and
ThreadSanitizer. Deterministic host-local stress covers single-handler
serialization, repeated worker creation/destruction, worker joins, private

validate implementation mechanics; portable claims come from shared evidence.
