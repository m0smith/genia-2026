# `collect`

**Category:** `flow` &nbsp;|&nbsp; **Arity:** 1

```genia
collect(source)
```

Return list data from a list or by materializing a Flow.

## Arguments
- `source`: a list or Flow to materialize

## Returns
- a list containing every item of `source`

## Notes
- materializing a Flow consumes it to completion; a Flow is single-use
