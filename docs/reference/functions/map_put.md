# `map_put`

**Category:** `map` &nbsp;|&nbsp; **Arity:** 3

```genia
map_put(map, key, value)
```

Return a new map with `key` set to `value`.

## Arguments
- `map`: the source map (returned unchanged)
- `key`: the key to set
- `value`: the value to associate with `key`

## Returns
- a new map with `key` mapped to `value`
