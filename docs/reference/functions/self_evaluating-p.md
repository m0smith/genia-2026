# `self_evaluating?`

**Category:** `syntax` &nbsp;|&nbsp; **Arity:** 1

```genia
self_evaluating?(expr)
```

Check whether a quoted expression is self-evaluating.

## Arguments

* `expr`: quoted expression data

## Returns

* `true` for numbers, strings, booleans, `nil`, and `none`
* `false` otherwise
