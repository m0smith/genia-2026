# `sheet_records`

**Category:** `Sheets` &nbsp;|&nbsp; **Stability:** Experimental

```genia
sheet_records(sheet)
```

Eagerly convert a Sheet to an ordered List of row Maps, preserving raw keys and cells. Zero rows lose column schema; non-Sheet input raises TypeError.
