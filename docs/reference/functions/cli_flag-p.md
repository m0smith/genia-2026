# `cli_flag?`

**Category:** `cli` &nbsp;|&nbsp; **Arity:** 2

```genia
cli_flag?(opts, name)
```

Check whether parsed options contain a truthy flag value.

## Arguments
- `opts`: parsed options map
- `name`: option name string

## Returns
- `true` when the named option is truthy, otherwise `false`
