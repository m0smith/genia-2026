# `split`

**Category:** `string` &nbsp;|&nbsp; **Arity:** 2

```genia
split(value, sep)
```

Split `value` on the explicit separator `sep`.

## Arguments
- `value`: string to split
- `sep`: separator substring to split on

## Returns
- list of the substrings between separators
- leading and trailing empty segments are dropped
