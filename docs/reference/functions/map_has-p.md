# `map_has?`

**Category:** `map` &nbsp;|&nbsp; **Arity:** 2

```genia
map_has?(map, key)
```

Report whether a map contains `key`.

## Arguments
- `map`: the map to check
- `key`: the key to look for

## Returns
- `true` when `key` is present, otherwise `false`
