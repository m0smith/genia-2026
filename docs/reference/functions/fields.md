# `fields`

**Category:** `awk` &nbsp;|&nbsp; **Arity:** 1

```genia
fields(row)
```

Split a row into whitespace-separated fields, keeping the original row first.

## Arguments
- `row`: string row

## Returns
- list containing `row` followed by its whitespace-separated fields
