## 2) Findings

**F1 — stale host-status text across more than a dozen files (repaired).** The
protected `host_status` fact in `docs/contract/semantic_facts.json`, and the docs
that repeat it, still called C++ "the bounded R26 production host". Four surfaces
were staler still and said R25: `GENIA_STATE.md` ("implements the bounded R25
floor"), `hosts/README.md`, `docs/host-interop/HOST_CAPABILITY_MATRIX.md`, and the
README's R25 floor sentence. The capability matrix also listed `-p` and Flow
phase 1 as "Not Implemented" for C++. All are updated to R27 with the two
capabilities described accurately. `tests/doc/test_roadmap_split.py` pinned the
sentence "R8 through R26 are complete" and was updated to match; the doc-sync
tests and the full non-loopback suite found no other test pinning a stale status. This change touched a protected fact in one pass across
many files; the update was mechanical, asserted per file, and verified by the
semantic-sync tests.

**F2 — the release title no longer matched the delivered scope (repaired).** R27
was titled "C++ Flow, Pipe Mode, and HTTP Serving" but its HTTP work was deferred.
The title is now "C++ Flow and Pipe Mode" in the roadmap, sequence, burn-down, and
release docs, with the original title recorded on the release page.

**O1 — C++ `-c` behavior changed outside the gated set (observation, evidenced).**
While building pipe mode, differential testing showed the reference host wraps
*every* runtime error raised inside a pipeline stage. On C++ `main` before E27-2,
`1 |> nope` under `-c` printed an unwrapped message. It now matches Python. This is
covered by two ungated `error` cases added in E27-5, so it is regression-protected
rather than incidental.

**O2 — the differential harnesses are not in the repository.** The 89 `-c` and 45
`-p` program comparisons against the reference host were run from scratch scripts.
They found real divergences (for example the pipeline-stage error wrapper in O1)
but are not reproducible from a checkout. What *is* reproducible is the shared-case set they
produced (21 cases).

**O3 — CI status was not independently verified here.** This audit re-ran the
shared runner, parity gate, and test suites locally. It did not inspect the hosted
CI results for the merged PRs, so it makes no claim about them.
