# R25–R28 — C++ Host Expansion and Sheet Record Pipelines

Status: Planned roadmap detail — non-authoritative. `GENIA_STATE.md` remains final authority for implemented behavior.

These releases are the former R22-R25 plan shifted by three positions after R21-R23 became explicit numeric releases. Scope intent is unchanged by the renumbering.

## Release R25 — C++ Stateful Runtime and Concurrency

**Status: Planned, not active.** Depends on R24.

Theme: add stateful C++ capabilities only after ownership, cycles, cleanup, and concurrency observations are explicit.

Candidate scope retains the prior plan: C++ ownership/lifetime strategy; portability promotion for refs/cells/process observations; threading/mailbox/failure/cleanup mapping; deterministic stress/race/lifecycle tests; evidence-based capability claims; no language scheduler, async/await, supervision tree, distributed actors, HTTP, or resource IO.

## Release R26 — C++ REPL and Data Bridges

**Status: Planned, not active.** Depends on R24; bridge tracks remain separately gated.

Theme: extend the minimal host with interactive evaluation and deterministic data boundaries.

Candidate scope retains the prior plan: REPL behavior plus promoted bytes/UTF-8, strict JSON, and ZIP boundaries; duplicate-key rejection, JSON safe ranges, Unicode validation, nesting limits, deterministic output, normalized Outcomes/errors, and R16 capability-tagged evidence. Pipe mode/Flow and HTTP remain later.

## Release R27 — C++ Flow, Pipe Mode, and HTTP Serving

**Status: Planned, not active.** Depends on R24 and on any R25/R26 behavior actually required by approved designs.

Theme: complete the largest remaining portable runtime surfaces without turning C++ internals into Genia semantics.

Candidate scope retains the prior plan: lazy pull-based single-use Flow phase 1, `-p`/pipe mode over Flow, explicitly promoted HTTP/server contracts, R8 lifecycle/server behavior, capability-aware differential evidence, and honest unsupported classifications.

## Release R28 — Sheet Record Pipelines

**Status: Planned, not active.** Focused killer-workflow release after the C++ host-parity arc.

Theme: make immutable Sheets explicit sources and destinations for AWK-like, Outcome-aware record pipelines without implicit Sheet-to-Seq conversion or an AWK execution mode.

Candidate scope retains the prior R25 decisions: explicit Sheet-to-record boundary; deterministic row/column order and per-record context; bounded Flow behavior and finalization; R14 repeated element scopes; ordinary `scan`/`reduce` state; schema-preserving versus explicit schema-changing operations; Outcome/protected-value preservation; shared eval/flow/error evidence.

Explicitly still excluded: `$0`/`$1`/`NR`/`NF` syntax, mutable row globals, implicit Sheet Seq compatibility, dataframe/query DSLs, joins/grouping/windowing, automatic coercion, and a second Outcome/Template/validation model.
