## 1. Implementation boundaries (DS6, DS7)

Python reference host: implement column/2 and with_column/3 as small helpers in src/genia/sheet.py; register in both import paths and the runtime-public fixed-arity host-function groups in src/genia/builtins.py, following sheet_records/1. Reuse GeniaSheet, _ensure_sheet, _freeze_column_name, name_to_values and _sheet_error. No change to existing Sheet helpers or value representation.

Implement map2/3 as a small host-backed List helper in builtins.py, using the existing raw evaluator invocation (apply_raw_fn) rather than duplicating callable dispatch. Register the fixed-arity runtime-public group. This is a deliberate narrow exception to the prelude preference: baseline list.genia map uses apply_raw but does not eagerly validate callees, and pairs_checked truncates. No existing general source-level callable predicate and normalized TypeError facility have been established for this combination. A prelude implementation would require new host validation/error seams and extra private bindings; one cohesive host helper is smaller. Do not add a public predicate, error primitive or host-specific language semantics. Reuse the ordinary evaluator rather than direct Python callback calls. R33 may reconsider implementation placement without changing behavior. No performance work.

Use the existing ordinary function-group registration, aliasing, module visibility, ownership, arity and pipeline rules. No special compiler names, none-propagation exemption, Flow adapter or special pipeline rewrite. Existing outer ordinary-call Outcome rules remain: structural validation applies once the call reaches the helper; raw callback invocation is separate. Entry immutable-name reservation follows existing runtime-public behavior. The new names have no existing public definitions per the independent contract review.

## 2. Sheet algorithms (DS1, DS4, DS8)

column: validate Sheet first via _ensure_sheet; canonicalize supplied name with _freeze_column_name; look up in name_to_values; missing key raises the approved count/payload-free diagnostic via _sheet_error. Return a fresh outer List of stored tuple cells, retaining exact references. No callbacks or IO.

with_column: validate Sheet, canonicalize legal name, reject duplicate canonical identity, validate List, recursively reject declassification authority in values using contains_declassification_authority, compare len(values) to stored row_count, then construct GeniaSheet with appended (exact supplied name, tuple(values)), sharing old column tuples and row count. Never round-trip through rows or make_sheet: that would lose zero-column retained row counts or change validation precedence.

DS8: name legality wins before values validation. An authority-bearing name must fail existing _freeze_column_name/canonical legal-key validation; do not use a new combined name/values authority scan or a new name diagnostic. Review nested authority keys against canonicalizer during RED; if existing legal-key validation would accept an authority-bearing name, STOP for a protected-boundary decision rather than silently allowing storage or changing R18. Values authority rejection precedes length mismatch. No scan/repair of legacy source cells, no changes to derive or collect_sheet.

Structural Sheet errors introduced here are marked via _sheet_error; _ensure_sheet already marks its error. Preserve inherited illegal-name error types/messages and marking, including the existing unmarked protected-name case. No broad diagnostic cleanup or raw repr in new messages.

## 3. List algorithm (DS2–DS6)

Validate callback first as an ordinary callee category: GeniaMap, string projector, or callable(value) in the reference host, matching branches in callable.py invoke_callable. This is a category check, not an invocation or arity probe. Do not run a callback, inspect effects or eagerly resolve a closed callable's invocation status. Existing invocation rules govern failed/uncommitted closed values when a pair is actually invoked. A wrong-arity callable with two empty Lists returns []; with nonempty equal Lists it fails on first invocation using ordinary error behavior. Noncallees fail even with empty Lists.

Then validate xs List and ys List in that order (not Seq or Flow, no conversion); length equality before any callback. Use exact contract TypeError strings and decimal length counts. Structural map2 errors are ordinary unmarked TypeError, consistent with pairs and map; when used in a pipeline the existing wrapper may include stage context. Do not catch or re-mark callback errors.

After validation iterate corresponding indices once, using apply_raw_fn(f, [xs[i], ys[i]]) or the exact same evaluator invocation path (tail_position=False, callee_node=None, skip_none_propagation=True). Append returned values unchanged to a fresh outer List. No rollback or partial return on failure. This is the reference-host algorithm, not a new language iteration construct. Leave map, pairs (shorter-input truncation), zip, Flow, existing callable and Outcome mechanisms untouched. Do not implement map2 by pairs or by changing existing prelude helpers.
