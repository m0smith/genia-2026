# State record (non-authoritative provenance)

This directory is an **audit and provenance layer**, not documentation to learn Genia from and not part
of the truth hierarchy. It holds, verbatim and unedited, text that was displaced from or condensed out of
`GENIA_STATE.md` during the #1099 distillation, so that the exact earlier wording stays discoverable.

Rules:

- `GENIA_STATE.md` is the final authority. Nothing here defines or widens implemented behavior; if a
  record disagrees with STATE, STATE wins.
- Read the current documents first: `GENIA_STATE.md`, `GENIA_RULES.md`, the release pages in
  `docs/releases/`, the approved contracts in `docs/design/`, and the generated reference in
  `docs/reference/`. Open a record only to see the exact historical text of a displaced passage.
- Records are generated by `tools/state_records.py` from `docs/analysis/state-distillation-migration-map.json`
  and verified by `tests/doc/test_state_records.py`. Do not edit them by hand.
- Each block carries a provenance line naming the baseline commit, baseline line range, and ledger row.
